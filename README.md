# IBMS — Informatic business and management skills

> **Innovation · Formation · Technologie · Transformation Digitale**

IBMS — Institut de Management et des Business Solutions — est une plateforme numérique dédiée à la formation, à l'innovation, aux services numériques et au développement de solutions technologiques.

La plateforme rassemble dans un même environnement les différentes activités d'IBMS et permet aux visiteurs, étudiants, professionnels et partenaires de découvrir les formations, services, projets, ressources, événements et l'écosystème de l'institution.

---

## 🌍 À propos d'IBMS

IBMS accompagne le développement des compétences et des solutions numériques à travers une approche orientée vers la technologie, l'innovation, la formation et la transformation digitale.

La plateforme permet notamment de :

* découvrir IBMS ;
* consulter les formations ;
* explorer les services ;
* découvrir les projets réalisés ;
* consulter les articles et guides ;
* découvrir les événements ;
* découvrir l'équipe ;
* découvrir les partenaires ;
* contacter IBMS.

## 🚀 Installation

### Cloner le repository

```bash
git clone https://github.com/DebugNinja10/IBMS_PLATEFORME_SN.git
```

### Entrer dans le projet

```bash
cd IBMS_PLATEFORME_SN
```

### Installer les dépendances

```bash
npm install
```

### Lancer le projet

```bash
npm run dev
```

Le terminal affichera l'adresse locale permettant d'accéder à la plateforme.

---

## 🏗️ Production

Pour générer la version de production :

```bash
npm run build
```

Pour prévisualiser la version de production :

```bash
npm run preview
```

## 🔐 Variables d'environnement

Les fonctionnalités nécessitant des services externes peuvent utiliser des variables d'environnement.

Créer un fichier local :

```text
.env.local
```

Exemple :

```env
VITE_API_URL=
```

Les variables nécessaires dépendent de la configuration réelle du projet.

### ⚠️ Sécurité

Ne jamais publier sur GitHub :

* clés API ;
* mots de passe ;
* tokens ;
* credentials ;
* secrets ;
* fichiers `.env` contenant des informations sensibles.
